# RAG Platform — Admin Console

Control plane for the RAG buyer-intelligence platform.

Tabs: Projects (intake) · Signals & Tags (rag-config editor) · Prompt Studio · Cost Center · API Keys.

Connect with the platform API key (top right). Without a key the console
shows the cached Equinix POC taxonomy in read-only/local mode.

**Keep this Space private** — it is an operator tool.
